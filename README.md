# mencoba

Komponen React `AlurMetodologi` — diagram alur metodologi penelitian copula, dioptimalkan untuk presentasi horizontal.

## Fitur

- **Layout Horizontal**: Flowchart berjalan dari kiri ke kanan (ideal untuk slide presentasi)
- **Font Proxima Nova**: Semua elemen menggunakan `'Proxima Nova', 'Nunito', 'Montserrat', sans-serif`
- **Responsive untuk Presentasi**: Card dan spacing dioptimalkan untuk tampilan landscape

## Menjalankan

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
